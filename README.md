# 《脱贫：现代化之路》游戏介绍网页

基于《中国式现代化——游戏策划书》及确认后的视觉方案制作。此网站为课程小组作业的游戏概念介绍，不是可游玩的游戏，也不代表游戏已发布。

## 打开网页

直接双击 `index.html` 即可在现代浏览器中查看，无需安装依赖、联网或构建。

也可以在本目录运行 `python -m http.server 8080`，然后访问 `http://localhost:8080`。

## 文件说明

- `index.html`：首页概览，包含三个模块的独立页面入口。
- `gameplay.html`：核心玩法详情，包含建设循环、四大玩法、资源取舍与协作收集。
- `journey.html`：成长之路详情，包含三篇章、起步任务与成长成就。
- `stories.html`：乡村故事详情，包含修路、饮水、通电任务及村民角色介绍。
- `styles.css`：颜色、字体、布局与手机适配。
- `details.css`：三个详情页的布局，以及首页模块跳转按钮样式。
- `script.js`：各页面共用的手机导航与首页成长阶段切换。
- `assets/hero-village.png`：首屏乡村插画。
- `assets/village-scenes.png`：2 列 × 4 行的场景插画图集，以 CSS 背景定位显示。

## 调整内容

- 修改首页游戏标题、介绍：编辑 `index.html`。
- 修改模块详情文案：分别编辑 `gameplay.html`、`journey.html`、`stories.html`。
- 修改首页三篇章切换文案：编辑 `script.js` 中的 `stages`。
- 四页共用同一组导航链接；修改导航、品牌或页脚时同步更新四个 HTML 文件。
- 修改主色、底色与字体：编辑 `styles.css` 开头的 `:root` 变量。
- 替换场景图集时，应保留 2 列 × 4 行布局及每格 4:3 比例；否则需同步修改 `.scene` 的背景尺寸和定位。

首页玩法插画链接到详情页对应小节；“探索完整玩法”“查看完整成长历程”“走近乡村故事”分别进入三个独立页面。顶部导航也可直接进入详情页，各详情页提供章节目录、返回首页和下一个模块入口。

页面包含语义化导航、跨页面跳转、键盘可操作的首页阶段选项卡及减少动态效果的偏好支持。所有资源均保存在本地，没有外部字体、统计或账号服务。整个目录复制或解压后即可使用，需保持 HTML、CSS、JS 和 assets 的相对位置不变。

## 插画说明

图片使用内置图像生成工具制作，为课程概念插画。生成方向为：简洁大方的现代中国乡村手绘插画，米白、青绿与稻金配色，白墙青瓦、通村路、石桥、稻田与现代农业设施，统一风格并保留留白。详细生成说明保存在 `assets/image-prompts.md`。

## GitHub Pages 发布

建议仓库名：`roots-to-rise`。

此目录可作为独立的 GitHub 仓库。四个 HTML 页面、CSS、JavaScript 与图片均使用相对路径，可以发布在 GitHub Pages 的项目子路径下。`.nojekyll` 用于直接托管静态文件。

首次发布：将本目录文件上传到 GitHub 仓库的 `main` 分支；进入 Settings → Pages，在 Source 选择 Deploy from a branch，分支选择 main，目录选择 /(root)，然后保存。成功后请以 Pages 页面实际显示的网址为准。

后续更新：修改源码并提交到 main，GitHub Pages 会重新发布。GitHub 上的仓库是源码管理入口，Pages 链接是给访客浏览网站的入口。
